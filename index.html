🧼 WHAT IT DOES

  • Searches %APPDATA%, %LOCALAPPDATA%, %TEMP%, %ProgramFiles%, %ProgramData%, %USERPROFILE%\Documents, Downloads, Desktop for files/folders containing "superiority" → deletes them.
  • Removes registry keys: HKCU\Software\Superiority, HKLM\Software\Superiority, HKCU\Software\Classes\superiority and autorun value.
  • Clears USN Journal on C: D: E: F: G: (if exist).
  • Clears Windows Event Logs: NTFS/Operational, System, Security, Application.
⚠️ Note: Administrator rights required! The script automatically requests elevation.
💡 No files or folders are deleted outside the "superiority" pattern. Safe for daily use.

❓ TROUBLESHOOTING

  • "Python not recognized" → Install Python from python.org (add to PATH).
  • Registry keys remain → Run script as Administrator (auto-elevation works, but right-click → "Run as administrator" if needed).
  • USN Journal error → Normal if drive is missing or filesystem is not NTFS.
